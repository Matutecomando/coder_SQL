Este proyecto corresponde a la pre entrega 4 del curso de sql.
El objetivo es aplica  consultas SQL sobre las tablas clientes, productos y ventas utilizando join, left join , funciones de agregación , group by, having, coalesce y funciones de ventana.
Las consultas permiten analizar la rentabilidadr categoría , identificar clientes sin compra y conocer el producto más comprado por cada cliente junto  con la fecha de su ultima transacción.
